📧 Système d'Emails Backend

Explication Complète du Système de Notifications par Email - Laravel

🌐 Vue d'Ensemble du Système

🎯 Concept Principal

Laravel utilise le système Mailable pour gérer les emails. Chaque type d'email est une classe qui définit:

  • ✉️ Le sujet de l'email
  • 📄 Le template Blade utilisé
  • 📊 Les données passées au template
  • 📎 Les pièces jointes (si nécessaire)

🏗️ Structure d'un Mailable

Exemple: CandidatureAcceptee.php

// app/Mail/CandidatureAcceptee.php namespace App\Mail; use App\Models\{Candidature, Stage}; use Illuminate\Mail\Mailable; use Illuminate\Mail\Mailables\{Content, Envelope, Address}; class CandidatureAcceptee extends Mailable { public $candidature; public $stage; // 1. CONSTRUCTEUR - Reçoit les données public function __construct(Candidature $candidature, Stage $stage) { $this->candidature = $candidature; $this->stage = $stage; $this->encadrant = $stage->encadrant; } // 2. ENVELOPE - Définit l'expéditeur et le sujet public function envelope(): Envelope { return new Envelope( from: new Address(config('mail.from.address'), config('mail.from.name')), subject: '🎉 Candidature acceptée - ' . $this->offre->titre, ); } // 3. CONTENT - Définit le template et les données public function content(): Content { return new Content( view: 'emails.candidature-acceptee', with: [ 'stagiaire' => $this->stagiaire, 'offre' => $this->offre, 'stage' => $this->stage, 'encadrant' => $this->encadrant, ] ); } // 4. ATTACHMENTS - Pièces jointes (optionnel) public function attachments(): array { return []; } }

// Accessibles dans le template Blade public $candidature; public $stage; public $encadrant; public $stagiaire; public $offre;

🚀 Comment Envoyer un Email

Méthode 1: Envoi Simple

// Dans un Controller use Illuminate\Support\Facades\Mail; use App\Mail\CandidatureAcceptee; // Préparation des données $candidature = Candidature::find(10); $stage = Stage::find(5); // Envoi de l'email Mail::to($candidature->stagiaire->user->email) ->send(new CandidatureAcceptee($candidature, $stage)); // ✅ L'email est envoyé immédiatement!

Méthode 2: Envoi en File d'Attente (Queue)

// Pour les gros volumes, utiliser les queues Mail::to($email) ->queue(new CandidatureAcceptee($candidature, $stage)); // L'email sera envoyé en arrière-plan par un worker // Avantage: Ne ralentit pas la requête HTTP

Méthode 3: Envoi Multiple

// Envoyer à plusieurs destinataires $emails = ['user1@example.com', 'user2@example.com']; Mail::to($emails) ->cc('admin@example.com') // Copie ->bcc('archive@example.com') // Copie cachée ->send(new MonEmail());
⚙️ Configuration du Système Email

Fichier: config/mail.php

// Configuration principale return [ // Driver par défaut (smtp, log, array, etc.) 'default' => env('MAIL_MAILER', 'smtp'), // Configuration SMTP 'mailers' => [ 'smtp' => [ 'transport' => 'smtp', 'host' => env('MAIL_HOST', 'smtp.mailtrap.io'), 'port' => env('MAIL_PORT', 2525), 'username' => env('MAIL_USERNAME'), 'password' => env('MAIL_PASSWORD'), ], ], // Adresse expéditrice globale 'from' => [ 'address' => env('MAIL_FROM_ADDRESS', 'noreply@plateforme.com'), 'name' => env('MAIL_FROM_NAME', 'Plateforme de Stages'), ], ];

Fichier: .env (Variables d'environnement)

# Configuration email dans .env MAIL_MAILER=smtp MAIL_HOST=smtp.mailtrap.io MAIL_PORT=2525 MAIL_USERNAME=your_username MAIL_PASSWORD=your_password MAIL_ENCRYPTION=tls MAIL_FROM_ADDRESS=noreply@plateforme.com MAIL_FROM_NAME="Plateforme de Stages" # Pour tester en développement, utiliser 'log' pour voir les emails dans storage/logs/laravel.log MAIL_MAILER=log

✨ Bonnes Pratiques

💡 Conseils Importants

1. Utiliser les Queues pour les Emails

// Dans la classe Mailable, ajouter l'interface ShouldQueue class MonEmail extends Mailable implements ShouldQueue { use Queueable; // Maintenant Mail::send() utilisera automatiquement la queue }

2. Tester les Emails en Développement

// Option 1: Utiliser 'log' driver pour voir dans les logs MAIL_MAILER=log // Option 2: Utiliser Mailtrap.io pour tester sans envoyer réellement MAIL_MAILER=smtp MAIL_HOST=smtp.mailtrap.io

3. Gestion des Erreurs

try { Mail::to($email)->send(new MonEmail()); } catch (\\Exception $e) { Log::error('Erreur envoi email: ' . $e->getMessage()); // Gérer l'erreur proprement }

4. Templates Responsives

Tous les templates Blade utilisent un design responsive pour s'adapter aux mobiles et tablettes.

Processus Étape par Étape

// 1. CONTROLLER - Admin accepte une candidature public function accept(Request $request, $id) { $candidature = Candidature::findOrFail($id); // 2. Mise à jour BDD $candidature->update(['statut' => 'accepte']); // 3. Création du stage $stage = Stage::create([...]); // 4. ENVOI EMAIL STAGIAIRE Mail::to($candidature->stagiaire->user->email) ->send(new CandidatureAcceptee($candidature, $stage)); // 5. ENVOI EMAIL ENCADRANT Mail::to($encadrant->user->email) ->send(new NouveauStagiaire($candidature->stagiaire, $stage)); // 6. Notifications in-app NotificationService::candidatureAcceptee(...); } // ✅ Résultat: 2 emails envoyés + 2 notifications créées
